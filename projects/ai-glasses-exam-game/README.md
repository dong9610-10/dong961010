# AI 안경 수능 게임

## 개요

시험장에서 AI 안경을 사용하는 상황을 소재로 한 브라우저 기반 게임입니다. 제한 시간 안에 문제를 풀고, 감독관 감시와 적발 위험을 고려하도록 구성했습니다.

- **형태:** 개인 웹게임 프로젝트
- **진행 상태:** 개발 및 개선 중
- **실행 주소:** [웹게임](https://ai-glasses-exam-room.sage-crab-8888.chatgpt.site/) (이전에 공유한 주소이며 현재 접속 가능 여부는 별도 확인 필요)

## 기획 요소

| 항목 | 내용 |
|---|---|
| 시험 진행 | 제한 시간 안에 문제 풀이 |
| 감독관 | 이동 및 감시 상태에 따라 위험도 변화 |
| 위험·보상 | 정답 확인 행동과 적발 위험 사이의 선택 |
| 결과 화면 | 점수와 시험 결과를 확인하는 구조 |
| 반복 플레이 | 문제 변화, 결과 및 재도전 방식을 개선하는 방향 |

위 항목에는 기획 중이거나 수정 중인 기능도 포함됩니다. 모든 기능의 최종 구현 완료를 뜻하지 않습니다.

## 작업 방식

- 게임 규칙 및 사용자 흐름 기획
- ChatGPT로 요구사항과 개선안을 정리
- Codex를 활용한 코드 구현·수정
- 실제 플레이 결과를 토대로 문제점 확인 및 개선
