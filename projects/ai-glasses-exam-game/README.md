# 🎮 AI 안경으로 서울대 가기 (AI Glasses Exam Game)

> **Personal Project · AI-assisted Web Game · In Progress**

## 프로젝트 개요

가상의 시험장에서 AI 안경을 사용하는 상황을 소재로 한 **인터랙티브 웹게임**입니다. 시험 감독관의 감시와 적발 위험, 정답 선택, 게임 결과 등으로 긴장감과 반복 플레이의 재미를 만들고자 기획했습니다.

- **Live demo:** [웹게임 열기](https://ai-glasses-exam-room.sage-crab-8888.chatgpt.site/) *(기존 공유 주소 — 접속 가능 여부는 직접 확인 필요)*
- **역할:** 게임 콘셉트 기획, 규칙과 상호작용 설계, AI 개발 도구를 이용한 구현·수정, 플레이 테스트
- **활용 도구:** ChatGPT, OpenAI Codex 등 AI-assisted development tools
- **진행 상태:** 기능 개선 및 반복 테스트 중

## 게임 기획의 핵심

1. **위험과 보상:** 정답을 확인하려는 행동과 감독관에게 적발될 위험 사이의 선택
2. **실시간 상호작용:** 제한 시간, 문제 풀이, 감독관 감시 상태에 따른 반응
3. **게임 결과:** 점수 및 결과 화면을 통한 피드백
4. **반복 플레이:** 난이도·문제 변화·결과 시스템 등을 지속 개선

> 위 항목은 프로젝트의 기획·개발 범위를 요약한 것입니다. 버전마다 실제 구현 상태가 다를 수 있으며, 미구현 기능을 완료된 기능으로 표시하지 않습니다.

## 개발 과정에서 중점적으로 다룬 것

- 아이디어를 실제 플레이 가능한 게임 규칙으로 바꾸기
- 사용자가 이해하기 쉬운 UI 및 결과 화면 설계
- AI 도구에 요구사항을 구체적으로 전달하고 결과를 테스트하며 수정하기
- 반복 플레이의 동기를 높일 개선안 도출하기

## 코드 및 자료 공개 계획

이 폴더는 우선 **프로젝트 소개 문서**로 작성되었습니다. 웹게임 원본 소스 코드는 아직 이 저장소에 업로드되지 않았습니다.

추후 소스 코드, 스크린샷, 실제 사용 기술, 실행 방법을 확인하여 추가할 예정입니다.

## 책임 있는 소개

실제 시험 부정행위를 위한 도구가 아닌, 허구의 상황을 소재로 한 게임 프로젝트입니다.
