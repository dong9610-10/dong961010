# Python 및 AI 실습

Python 기초부터 OpenAI API, Gradio를 활용한 애플리케이션 제작까지 실습한 내용을 정리합니다.

[날짜별 AI 교육 기록](../nvidia-ai-training/README.md)

## 실습 분야

| 분야 | 내용 |
|---|---|
| Python | 변수, 조건문, 반복문, 함수 |
| Responses API | 모델 호출, 입력과 지시문, 출력 제한 |
| 프롬프트 엔지니어링 | Few-shot, 반례 제시, 단계별 계산 |
| Gradio Interface | 계산기, BMI 계산기 |
| Gradio Blocks | 파일 분석기, 선형회귀 시각화 |
| Gradio ChatInterface | OpenAI API를 활용한 챗봇 |
