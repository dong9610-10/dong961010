# Image Generation

**참고 자료:** `[LLM] 02. Multimodal.pdf`, 13–26쪽  
**상태:** 개념 및 실습 조건 정리 / 실행 결과 미확인

## API 구분

| 목적 | 기능 | 결과 |
|---|---|---|
| 이미지 내용을 설명 | Responses API의 Vision 입력 | 텍스트 |
| 텍스트로 새 이미지 생성 | Images API `generate` | 이미지 |
| 기존 이미지 수정 | Images API `edit` | 편집 이미지 |

이미지 이해와 이미지 생성은 목적이 다르므로 입력·출력 형태에 맞는 API를 선택해야 합니다.

## 생성 이미지 저장 흐름

강의 19쪽과 24쪽의 예제에서는 이미지 생성 결과를 Base64 형식으로 전달합니다.

1. Images API 호출
2. 응답에서 Base64 문자열 추출
3. 문자열 디코딩
4. 이미지 파일 저장
5. Colab 또는 Gradio에서 결과 표시

Base64 문자열은 이미지 데이터를 문자로 표현한 것이므로 이미지 파일로 사용하려면 디코딩 과정이 필요합니다.

## Gradio 이미지 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| `gr.Image` | 이미지 한 장의 입력과 출력 |
| `gr.Gallery` | 여러 이미지 목록 표시 |
| `gr.ImageEditor` | 이미지를 불러와 레이어를 추가하고 결과 합성 |

ImageEditor 관련 데이터에는 `background`, `layers`, `composite`가 있습니다(23쪽).
