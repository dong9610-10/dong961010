# Multimodal 및 Vision

**참고 자료:** `[LLM] 02. Multimodal.pdf`, 4–12쪽  
**상태:** 개념 정리 / 실행 결과 미확인

## 개념

| 용어 | 설명 |
|---|---|
| Unimodal | 한 종류의 데이터 형태를 중심으로 처리하는 모델 |
| Multimodal | 텍스트·이미지·음성·영상 등 여러 형태의 데이터를 처리하는 모델 |
| Vision | 이미지의 시각적 특징과 텍스트 질문을 연결하는 기능 |
| Image-to-Text | 이미지를 입력받아 설명이나 답변을 텍스트로 생성하는 작업 |

## Image-to-Text의 기본 흐름

강의 9–10쪽에서는 이미지에서 특징을 추출하고 문장을 생성하는 과정을 다음과 같이 설명합니다.

1. **Vision Encoder:** 이미지의 시각적 특징을 추출
2. **Text Decoder:** 이미지 정보를 참고해 텍스트 생성
3. **Training:** 학습 단계에서 이미지와 텍스트의 관계를 학습

설명용 도식이므로 구체적인 모델 구조가 항상 동일한 것은 아닙니다.

## Responses API 입력 구조

하나의 메시지에 여러 입력을 포함할 수 있습니다.

- `role`: 메시지를 작성한 주체
- `content`: 텍스트·이미지·파일 등 입력 요소
- `input_text`: 질문이나 지시문
- `input_image`: 분석할 이미지

예를 들어 사용자 메시지 하나에 질문 텍스트와 사진을 함께 전달하고 텍스트 답변을 받을 수 있습니다.

## 주의할 점

강의 8쪽은 흐린 이미지, 작은 문자, 복잡한 시각 정보, 의료 영상 등의 해석 한계를 강조합니다. 중요한 판단에는 이미지 원본과 다른 자료를 대조해야 합니다.
