# Speech 및 Audio API

**참고 자료:** `[LLM] 02. Multimodal.pdf`, 27–47쪽  
**상태:** 개념 및 실습 조건 정리 / 실행 결과 미확인

## 주요 기능

| 기능 | 의미 | 입력 | 출력 |
|---|---|---|---|
| TTS | Text-to-Speech | 텍스트 | 음성 |
| STT / Transcription | Speech-to-Text | 음성 | 텍스트 |
| Translation | 음성 번역 | 음성 | 번역 텍스트 |

## TTS (29–32쪽)

텍스트를 입력받아 음성을 생성합니다. 강의에서 설명하는 주요 파라미터는 다음과 같습니다.

| 파라미터 | 용도 |
|---|---|
| `model` | 음성 생성 모델 |
| `input` | 읽어 줄 텍스트 |
| `voice` | 목소리 선택 |
| `instructions` | 억양·말투 등 지시 |
| `response_format` | 출력 음성 형식 |
| `speed` | 재생 속도 |

강의 지정 모델: `gpt-4o-mini-tts`.

## STT 및 번역 (33–42쪽)

STT는 음성을 텍스트로 변환합니다. 강의는 `gpt-4o-mini-transcribe`로 받아쓰기하는 예제를 제시합니다.

음성 번역은 번역 API를 직접 쓰거나 다음 방식으로 구성할 수 있습니다.

```text
음성 입력 → STT → 원문 텍스트 → LLM 번역 → 번역문
```

STT와 LLM을 연결하면 번역 대상, 표현 방식, 고유명사 처리 등을 프롬프트로 조정할 수 있습니다.

## Gradio Audio (43–45쪽)

`gr.Audio`로 업로드한 음성 파일이나 마이크 입력을 받을 수 있습니다.

- `sources`: `upload`, `microphone` 등 입력 방식
- `type`: 파일 경로 또는 NumPy 데이터
- `label`: 화면의 입력 이름

Colab에서 마이크 사용이 제한될 수 있으므로 브라우저 권한 및 Gradio 공유 화면에서 작동을 확인합니다.
