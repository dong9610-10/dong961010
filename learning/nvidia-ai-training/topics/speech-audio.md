## 1. TTS와 STT부터 구분하기 (p.29)

| 약어 | 풀어 쓴 이름 | 입력 → 출력 | 예시 |
|---|---|---|---|
| TTS | Text-to-Speech | 텍스트 → 음성 | 문장을 읽어주는 MP3 생성 |
| STT | Speech-to-Text / Transcription | 음성 → 텍스트 | 녹음 파일 받아쓰기 |
| Translation | Speech Translation | 음성 → 번역된 텍스트 | 음성 내용을 다른 언어로 변환 |

### 기억하기

- **TTS:** 글을 넣고 **소리**를 받습니다.
- **STT:** 소리를 넣고 **글**을 받습니다.
- **번역:** STT로 만든 글을 LLM에게 전달하여 원하는 언어·말투로 표현할 수도 있습니다. (p.41~42)

## 2. TTS API (p.30~32)

강의에서 소개한 음성 생성의 기본 요소는 다음과 같습니다.

| 파라미터 | 용도 |
|---|---|
| `model` | 음성 생성 모델 선택 |
| `input` | 음성으로 바꿀 텍스트 |
| `voice` | 음색 선택 |
| `instructions` | 말투·감정·억양 지시 |
| `response_format` | MP3, WAV 등 출력 형식 |
| `speed` | 재생 속도 |

슬라이드의 기본 흐름은 **텍스트 입력 → 음성 생성 API → 파일 저장 → 재생**입니다.

**강의 지정 모델:** `gpt-4o-mini-tts` (p.31).

## 3. Transcription / STT API (p.33~36)

강의 p.34의 도식은 음성 데이터를 여러 단계로 처리해 문자 출력을 만드는 모습을 보여줍니다.

실습의 큰 흐름:

1. 마이크로 녹음하거나 오디오 파일 준비
2. 파일을 이진 모드로 열어 API에 전달
3. STT 모델이 음성 내용을 텍스트로 반환
4. 받아쓴 글이 맞는지 직접 검토

**강의 지정 모델:** `gpt-4o-mini-transcribe` (p.35).

## 4. 음성 번역: 두 방식 (p.37~42)

### 방식 A — 번역 API 직접 사용

녹음 파일 → Translation 모델 → 번역 결과 텍스트

강의는 `whisper-1` 예시도 설명합니다. (p.37~40)

### 방식 B — STT → LLM

녹음 파일 → STT로 원문 추출 → LLM에 번역 지시 → 번역된 텍스트

**방식 B의 장점(강의 설명):** '비즈니스 영어로', '초등학생이 이해할 영어로', '고유명사를 그대로'처럼 결과의 스타일을 요청할 수 있습니다. (p.41~42)

> 언어 지원 범위, 가격, API 파라미터는 강의 내용이므로 구현 시 공식 최신 문서에서 재확인해야 합니다.

## 5. Gradio Audio 컴포넌트 (p.43~45)

| 항목 | 뜻 |
|---|---|
| `gr.Audio` | 음성 업로드·마이크 녹음을 받는 UI |
| `sources` | `upload`, `microphone` 노출 선택 |
| `type` | NumPy 배열 또는 파일 경로 등 입력 표현 |
| `label` | 사용자 화면에 보이는 이름 |

**강의 주의사항:** p.44는 Colab에서 마이크 접근 문제가 발생할 수 있어 외부 Gradio 페이지에서 권한을 확인하는 테스트 예시를 보여줍니다. 공개 링크를 만들 경우 누구나 접근할 수 있는지 주의해야 합니다.
