## 2. 오늘 배운 핵심 개념

| 개념 | 의미 | 핵심 코드 |
|---|---|---|
| `gr.Interface` | 하나의 함수를 입력·출력 컴포넌트에 쉽게 연결 | `gr.Interface(fn=..., inputs=..., outputs=...)` |
| `gr.Blocks` | 여러 UI 요소의 배치와 상호작용을 직접 구성 | `with gr.Blocks() as demo:` |
| `gr.File` | 사용자가 파일을 업로드하도록 하는 입력 | `gr.File(type="filepath")` |
| `gr.Plot` | Matplotlib 등의 그래프 출력 | `gr.Plot()` |
| 버튼 이벤트 | 버튼을 누르면 지정한 Python 함수 실행 | `button.click(fn=..., inputs=..., outputs=...)` |
| `gr.ChatInterface` | 대화형 채팅 UI를 손쉽게 만듦 | `gr.ChatInterface(fn=chat)` |
| `yield` | 스트리밍 답변을 조금씩 화면에 갱신 | `yield answer` |

### 3-1. 계산기 APP ✅

두 숫자와 연산 종류를 입력받는 함수를 `gr.Interface`로 연결했습니다.

```python
def calculator(a, b, operation):
    if operation == "나누기" and b == 0:
        return "Error : Division by Zero"
    # 다른 연산 분기는 별도로 구현
```

- **확인한 테스트:** `10 ÷ 0`
- **확인된 결과:** `Error : Division by Zero`
- **배운 점:** 특수 상황을 먼저 검사하면 0으로 나눌 때 오류를 방지할 수 있습니다.

### 3-2. BMI APP ✅

`BMI = 몸무게(kg) / (키(m) ** 2)` 공식을 함수로 구현했습니다.

```python
height_m = height_cm / 100
bmi = weight_kg / (height_m ** 2)
```

- **확인한 테스트:** 키 175cm, 몸무게 70kg
- **확인된 결과:** BMI 약 `22.86`, 상태 `정상`
- **배운 점:** 입력 단위(cm → m)를 바르게 변환한 후 계산해야 합니다.
- **주의:** BMI는 간단한 지표이며 개인의 건강 상태를 단독으로 판단하지 않습니다.

### 4-1. File 분석기 🟡

`gr.Blocks`로 파일 업로드·분석 버튼·결과 표시 영역을 구성하는 예시 코드를 안내했습니다.

예시 기능: 텍스트 계열 파일의 이름·크기·줄 수·단어 수·글자 수, 내용 미리보기.

```python
analyze_btn.click(
    fn=analyze_file,
    inputs=file_input,
    outputs=[result_output, preview_output]
)
```

- **확인 필요:** 실제 업로드와 분석 실행 결과
- **배운 개념:** 버튼에 함수를 연결하는 `click()` 이벤트

### 4-2. 선형회귀 시각화 🟡

가상 데이터의 기울기·절편·노이즈·개수를 조절하는 시각화 예시를 다뤘습니다.

```python
fitted_slope, fitted_intercept = np.polyfit(x, y, 1)
mse = np.mean((y - y_pred) ** 2)
```

- **핵심:** 데이터의 경향을 가장 잘 설명하는 1차 직선을 찾음
- **확인 필요:** 노이즈 0과 노이즈 10 비교 실행 결과
- **주의:** `np.polyfit`의 다항식 피팅은 신경망 학습과 다름
