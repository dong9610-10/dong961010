## 1. 학습 내용

Python 함수를 Gradio 웹 화면에 연결하는 방법을 실습했습니다. 간단한 함수형 화면부터 버튼 이벤트와 그래프, 채팅 인터페이스까지 다뤘습니다.

| 개념 | 역할 |
|---|---|
| `gr.Interface` | 함수를 입력·출력 컴포넌트와 연결 |
| `gr.Blocks` | 화면 구성과 이벤트를 직접 제어 |
| `gr.File` | 파일 업로드 입력 |
| `gr.Plot` | 그래프 출력 |
| `button.click()` | 버튼 클릭과 함수 실행 연결 |
| `gr.ChatInterface` | 채팅 화면 생성 |
| `yield` | 생성 중인 결과를 순차적으로 전달 |

### 2.1 계산기 — 실행 확인

사칙연산을 함수로 작성하고 `gr.Interface`에 연결했습니다.

```python
if operation == "나누기":
    if b == 0:
        return "Error : Division by Zero"
    return str(a / b)
```

- **테스트 입력:** 10 ÷ 0
- **확인한 출력:** `Error : Division by Zero`
- **확인 내용:** 예외 상황을 처리한 결과가 화면에 정상 표시됨

### 2.2 BMI 계산기 — 실행 확인

신장을 cm에서 m로 변환한 뒤 BMI를 계산했습니다.

```python
height_m = height / 100
bmi = weight / (height_m ** 2)
```

- **테스트 입력:** 175cm, 70kg
- **확인한 출력:** BMI 22.86, 정상
- **확인 내용:** 계산 결과와 상태 구분이 화면에 표시됨

### 2.3 파일 분석기 — 실행 미확인

`gr.Blocks`에서 파일 입력, 분석 버튼, 결과 텍스트 영역을 연결하는 코드를 안내했습니다.

```python
analyze_btn.click(
    fn=analyze_file,
    inputs=file_input,
    outputs=[result_output, preview_output]
)
```

텍스트 파일의 크기, 줄 수, 단어 수, 글자 수 및 앞부분 미리보기를 제공하는 예시입니다. 실제 파일 업로드 결과는 확인되지 않았습니다.

### 2.4 선형회귀 — 실행 미확인

기울기, 절편, 데이터 수, 노이즈를 조절해 생성한 데이터에 직선을 맞추는 예시를 다뤘습니다.

```python
fitted_slope, fitted_intercept = np.polyfit(x, y, 1)
mse = np.mean((y - y_pred) ** 2)
```

- `np.polyfit(x, y, 1)`: 데이터에 1차 다항식 적용
- MSE: 실제 값과 예측값 차이의 제곱 평균
- **추가 확인:** 노이즈 0과 10에서 결과 비교
