## 2. 핵심 개념

### 2.1 Multimodal과 Vision (4–12쪽)

- Unimodal: 한 종류의 데이터 형태를 중심으로 처리
- Multimodal: 텍스트·이미지·음성 등 여러 형태를 함께 처리
- Vision: 입력 이미지를 분석하고 질문에 대한 텍스트 답변 생성
- Image-to-Text: 이미지의 시각 정보를 텍스트로 연결

강의는 Vision Encoder와 Text Decoder를 중심으로 이미지 설명이 생성되는 흐름을 설명합니다. 이 구성은 개념을 이해하기 위한 예시이며 모든 모델의 내부 구조가 동일하다는 의미는 아닙니다.

Responses API에서는 메시지의 `role`과 `content`를 사용하고, `content`에 `input_text` 및 `input_image` 등을 함께 전달할 수 있습니다.

이미지 속 작은 글자, 흐린 텍스트, 전문 영상의 판독에는 오인식 가능성이 있으므로 결과를 검증해야 합니다.

[관련 개념 정리](../../topics/multimodal-vision.md)

### 2.2 Image Generation (13–26쪽)

| 작업 | API 및 기능 |
|---|---|
| 이미지 설명 생성 | Responses API + Vision 입력 |
| 새 이미지 생성 | Images API `generate` |
| 기존 이미지 편집 | Images API `edit` |

강의 예제에서는 생성된 이미지가 Base64 문자열로 반환되며, 이를 디코딩해 이미지 파일로 저장하고 Gradio에서 표시합니다.

- `gr.Image`: 이미지 한 장의 입력·출력
- `gr.Gallery`: 여러 이미지 출력
- `gr.ImageEditor`: 배경 이미지, 추가 레이어, 합성 결과 처리

강의에서 제시한 실습 모델은 `gpt-image-1-mini`입니다. 모델의 실제 지원 여부와 요금은 실행 시 확인이 필요합니다.

[관련 개념 정리](../../topics/image-generation.md)

### 2.3 Speech (27–47쪽)

| 기능 | 입력 | 출력 |
|---|---|---|
| TTS | 텍스트 | 음성 |
| STT / Transcription | 음성 | 텍스트 |
| Translation | 음성 | 번역된 텍스트 |
| STT + LLM | 음성 → 텍스트 | 번역·재작성된 문장 |

TTS는 음성의 목소리, 속도, 출력 형식 등의 옵션을 설정할 수 있습니다. STT는 녹음 파일을 입력받아 내용을 문자로 변환합니다.

강의는 STT 결과를 LLM으로 번역하면 문체나 대상 독자에 맞게 표현할 수 있다는 점을 설명합니다.

`gr.Audio`로 파일 업로드 및 마이크 입력을 받을 수 있습니다. 브라우저 마이크 권한과 공유 링크의 접근 범위를 확인해야 합니다.

강의 지정 모델: `gpt-4o-mini-tts`, `gpt-4o-mini-transcribe`. 모델별 가격 및 사용 조건은 현재 공식 문서를 별도로 확인해야 합니다.

[관련 개념 정리](../../topics/speech-audio.md)
