## 🔍 오늘의 핵심 3줄

1. **멀티모달(Multimodal)**은 텍스트 외에 이미지·영상·음성 같은 여러 데이터 형태를 함께 다루는 AI입니다. (p.4~5)
2. 목적에 따라 **Responses API(이미지 이해 → 텍스트), Images API(이미지 생성·수정), Audio API(음성 ↔ 텍스트), Realtime API(실시간 상호작용)** 등을 구분해야 합니다. (p.11, 14, 28)
3. 강의 최종 과제는 **이미지와 음성 기능을 모두 포함한 멀티모달 AI를 기획하고 코드로 구현**하는 것입니다. (p.49)

## 1. 개념 연결 — 이미지와 소리도 AI에게 전달하기

기존에 배운 텍스트 기반 API 사용에서 입력·출력의 종류가 확장됩니다.

| 원하는 작업 | 강의에서 제시한 API | 예시 |
|---|---|---|
| 사진 내용을 글로 설명 | Responses API | 사진을 넣고 '무엇이 보여?' 질문 |
| 프롬프트로 그림 제작 | Images API | '바다를 배경으로 한 강아지' 생성 |
| 원본 이미지 수정 | Images API edit | 같은 그림을 다른 스타일로 편집 |
| 텍스트를 읽어주는 음성 | Audio API TTS | 한국어 안내문 음성 생성 |
| 녹음한 말을 글로 변환 | Audio API Transcription | 마이크 입력 받아 문자 표시 |
| 음성 내용 번역 | Audio API / Transcription + LLM | 한국어 음성을 외국어로 번역 |
| 빠른 양방향 음성 상호작용 | Realtime API | 실시간 음성 대화 |

> API·모델 선택 표는 강의의 교육용 설명입니다. 실제 서비스 구현 시 지원 형식과 요금은 당시 공식 문서로 재확인해야 합니다.

## 2. Vision — 사진을 설명하는 AI (p.7~12)

- 입력된 사진의 시각 정보를 처리하고 텍스트 질문과 연결하여 답변을 만듭니다.
- 슬라이드의 I2T 설명은 **Vision Encoder → Text Decoder → 학습 시 이미지와 문장 비교**라는 흐름으로 구성되어 있습니다. (p.9~10)
- 선명하지 않은 글씨, 작은 텍스트, 전문 영상 판독 등에는 한계가 있음을 강조합니다. (p.8)
- Responses 메시지는 `role`과 `content`로 구성하며, `content`에 텍스트와 이미지 등 여러 요소를 함께 넣는 구조를 설명합니다. (p.11~12)

**복습 질문:** 왜 사진을 이해하는 API와 사진을 생성하는 API를 구분해야 할까요?

## 3. Image Generation — 그림 생성과 편집 (p.14~26)

- 새로운 그림을 만드는 `generate`와 기존 그림을 수정하는 `edit`의 목적을 구분합니다. (p.14~15)
- 생성 결과의 Base64 인코딩 데이터를 실제 이미지 파일로 바꾸어 저장·표시하는 흐름을 다룹니다. (p.19, 24)
- Gradio 컴포넌트: `Image`(한 이미지), `Gallery`(여러 이미지), `ImageEditor`(손그림·레이어 활용). (p.21~23)
- 제시된 실습: **속담 그림 퀴즈**(p.25), **그림판 Artist**(p.26).

**실습 권장 모델(강의 기준):** `gpt-image-1-mini` (p.18). 비용과 지원 사양은 실습 전 별도 확인이 필요합니다.

## 4. Speech — 말 듣기와 말하기 (p.27~47)

| 용어 | 의미 | 강의의 예시 |
|---|---|---|
| TTS | Text-to-Speech, 글 → 음성 | 텍스트로 음성 파일 생성 (p.29~32) |
| STT / Transcription | Speech-to-Text, 음성 → 글 | 녹음 파일을 받아 문자로 표시 (p.29, 33~36) |
| Translation | 음성 내용을 다른 언어의 텍스트로 번역 | 번역 API 또는 STT → LLM (p.37~42) |
| Gradio Audio | 웹 화면에서 마이크·파일 입력 | `sources`, `type` 등 입력 옵션 (p.43~45) |

강의는 **STT로 문자화한 뒤 LLM으로 원하는 말투·언어로 번역하는 방식**도 제안합니다. (p.41~42)

**실습 권장 모델(강의 기준):** TTS `gpt-4o-mini-tts` (p.31), STT `gpt-4o-mini-transcribe` (p.35). 음성 번역 예시에는 `whisper-1`이 소개됩니다. (p.37)

**녹음 사용 주의:** 강의는 Colab 안에서 오디오 장치 접근에 제한이 있을 수 있으므로 공유 Gradio 화면에서 마이크 권한을 확인하는 흐름을 보여줍니다. (p.44)

## 5. 강의 실습·과제 체크리스트

- [ ] **속담 퀴즈:** 랜덤 문제 → AI 그림 → 정답 판정 → 점수 → 다음 문제 (p.25)
- [ ] **그림판 Artist:** 손그림 이해 → 이미지 생성용 프롬프트 → 그림 재생성 → Gradio UI (p.26)
- [ ] **통역기 앱:** 한국어 녹음 → 언어 선택 → 원문 텍스트 → 번역 결과 텍스트·음성 (p.46)
- [ ] **영어 회화 퀴즈:** 한국어 문제 → 영어 음성 응답 → 점수·피드백 → 모범 답안·발음 (p.47)
- [ ] **최종 자율 프로젝트:** Image + Speech가 모두 포함된 AI 기획서 및 코드 작성 (p.49)

**현재 상태:** 체크 항목은 강의에 나오는 과제 목록일 뿐입니다. 실제 사용자가 실행했다는 증거가 없어 완료 표시를 하지 않았습니다.

## 6. 비용·보안·공개 주의

- 강의 슬라이드는 이미지·음성 생성 모델별로 비용 차이가 크다는 점을 강조합니다. (p.18, 31, 35, 37)
- 강의가 권장한 `gpt-4o-mini`, `gpt-image-1-mini`, `gpt-4o-mini-tts`, `gpt-4o-mini-transcribe`는 **해당 과제에서 지정한 모델**입니다. (p.49)
- 공개 GitHub에는 공용 API 키, 녹음 원본의 개인정보, 배포 권한이 없는 강의 슬라이드·코드를 그대로 업로드하지 않습니다.
- 슬라이드에 나온 가격·API 세부 옵션은 교육 자료의 설명을 기록한 것이며, 오늘의 실시간 정책으로 검증한 내용이 아닙니다.
