## 정리 기준

- 강의에서 설명한 내용과 실제 실행한 결과를 구분합니다.
- 코드의 핵심 구조, 실행 조건, 오류 및 해결 과정을 기록합니다.
- 확인되지 않은 결과를 완료된 것으로 표시하지 않습니다.
- 강의 원본과 개인 정보, API 키 등은 공개 저장소에 올리지 않습니다.

이 문서는 개인 학습 기록이며 교육기관의 공식 교재나 인증 내역이 아닙니다.
