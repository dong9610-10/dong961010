## ✅ 기록 원칙

1. **원자료 확인:** 그날 공유된 노트북·슬라이드·필기·실행 결과를 기준으로 작성합니다.
2. **확인된 것만 완료 표시:** 실행 결과가 확인되지 않았다면 `진행 중` 또는 `확인 필요`로 표시합니다.
3. **설명은 쉬우면서 정확하게:** 핵심 개념 → 예제 → 직접 구현 → 오류와 해결 → 복습 순서로 정리합니다.
4. **공개 안전성:** API 키, 개인정보, 강의 원본 전체 또는 재배포 권한이 불확실한 자료는 업로드하지 않습니다.
5. **내가 한 일과 AI가 도운 일 구분:** 직접 이해·구현·테스트한 부분과 AI-assisted 작업을 명확히 기록합니다.
6. **날짜별 누적:** 한 날짜의 추가 자료가 오면 해당 날짜 문서를 보완하고 목차를 유지합니다.
