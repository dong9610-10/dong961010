## 선택 가능한 예시 아이디어 — AI 보조 제안 (강의 요구사항 아님)

**사진을 설명해 주는 음성 가이드**

사용자가 사진을 업로드하면 Vision 기능이 사진을 텍스트로 설명하고, TTS가 설명을 음성으로 읽어주는 간단한 웹앱입니다.

- **이미지 요소:** 사용자 업로드 이미지 이해
- **음성 요소:** 설명 텍스트를 음성으로 생성
- **예상 흐름:** `gr.Image` → Vision 설명 → TTS 생성 → `gr.Audio`
- **장점:** 이미지·음성이라는 필수 조건을 단순한 인터페이스에서 연결 가능

이는 **AI가 제안한 초기 아이디어**이며, 실제 과제 주제나 구현 완료 여부를 의미하지 않습니다.
