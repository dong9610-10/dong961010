# 멀티모달 자율 프로젝트

**참고 자료:** `[LLM] 02. Multimodal.pdf`, 48–49쪽  
**상태:** 과제 조건 정리 / 주제 및 코드 미확정

## 과제 조건

- 이미지와 음성 기능을 모두 포함하는 멀티모달 AI를 제작
- 서비스 아이디어와 간단한 계획서 작성
- 계획서에 따라 프로젝트 코드 작성
- 강의에서 지정한 모델 사용

## 지정 모델

| 용도 | 강의 지정 모델 |
|---|---|
| 텍스트 및 Vision 관련 | `gpt-4o-mini` |
| 이미지 생성 | `gpt-image-1-mini` |
| 음성 생성 | `gpt-4o-mini-tts` |
| 음성 인식 | `gpt-4o-mini-transcribe` |

지정 모델은 강의 자료 49쪽을 기준으로 기록했습니다.

## 계획서 항목

| 항목 | 작성할 내용 |
|---|---|
| 프로젝트명 | 서비스 이름 |
| 목적 | 해결하고 싶은 문제 |
| 사용자 | 주요 이용 대상 |
| 이미지 기능 | 입력·처리·출력 방식 |
| 음성 기능 | 음성 인식 또는 생성 방식 |
| 처리 흐름 | 사용자 입력부터 결과 출력까지 |
| 화면 구성 | Gradio 인터페이스 |
| 사용 기술 | API 및 모델 |
| 검증 기준 | 성공 여부를 판단할 테스트 |
| 비용·보안 | API 사용량, 키와 개인정보 보호 |
